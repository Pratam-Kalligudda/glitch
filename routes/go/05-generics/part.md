---
title: "Generics"
goal: Write generic code where it pays off, and only there.
---
Generics let one function or type work over many types while the compiler still checks
every use. This part covers type parameters, constraints, generic types, inference, and the
two newest additions: generic methods (Go 1.27) and self-referential constraints (Go 1.26).
It ends with the harder question of when not to use them.
