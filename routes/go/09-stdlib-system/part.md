---
title: "Standard library: networks, processes and the system"
goal: Talk to networks, run processes and build command-line programs.
---
This part covers the packages a command-line tool or small service needs to talk to the world: flags, HTTP, URLs, TCP, child processes, logs, signals, build information and exit codes. Each stop uses a local server or a local program, so every output here is reproducible. linkcheck uses all of them in the capstone.
