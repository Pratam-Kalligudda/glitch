---
title: Emphasis and links
---
Wrap text in one asterisk for italic, two for bold, and backticks for inline code. A link is the text in square brackets followed by the address in round brackets.

```markdown
Notes is *small* and **fast**.
Run `npm start` to open it.
Read the [Markdown guide](https://www.markdownguide.org/).
```

| You write | You get |
|---|---|
| `*small*` | *small* |
| `**fast**` | **fast** |
| `` `npm start` `` | `npm start` |
