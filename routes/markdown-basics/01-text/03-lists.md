---
title: Lists
---
Start each item with `-` for a bulleted list or `1.` for a numbered one. Indent an item by two spaces to nest it under the one above.

```markdown
- Write notes
- Tag notes
  - by project
  - by date

1. Clone the repository
2. Install dependencies
3. Start the app
```

> [!NOTE]
> Numbered lists renumber themselves. Writing `1.` on every line still renders as 1, 2, 3, which keeps diffs small when you insert a step.
