---
title: Headings and paragraphs
---
A line starting with `#` is a heading. More `#` signs make a smaller heading, down to six. Text separated by a blank line is a new paragraph; a single line break inside a paragraph is ignored.

```markdown
# Notes

A short project for keeping notes.

## Install

Clone the repository and open the folder.
This line joins the one above it.
```

Use one `#` heading per file, at the top. Do not skip levels: a `###` belongs under a `##`.
