---
title: "Step 2: publish it"
done_when: The repository page on GitHub shows your README rendered below the file list.
---
Commit the README on its own, as in [[git-basics/commit]], then push it as in [[git-basics/remote]].

```bash
git add README.md
git commit -m "Add README"
git push
```

GitHub renders `README.md` from the root of the repository on its front page. Check every heading, list and table there, not just in your editor.
