---
title: Code blocks
---
Put three backticks on the lines before and after a block of code. Name the language after the opening backticks so GitHub can colour it.

````markdown
```bash
npm install
npm start
```
````

Inline code uses single backticks, as in [[emphasis-links]]. To show backticks inside a block, fence it with four backticks instead of three, which is how the example above is written.
